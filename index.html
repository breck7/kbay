List something

Have something a neighbor might need? Film a short video, add the file to the listings/ folder, and send a pull request. Listings are video only.

Name the file like this, in this order, with a space-hyphen-space between each part:

Title - FirstName - Location - Price - Phone.mp4

Example:

Kids Bike - Breck - Wahiawa - 40 - 808-555-0123.mp4

The title can have spaces. Add obo after the price if you will take a lower cash offer, like 40obo. The phone number can be written with or without dashes. Use your real first name and a number friends can call or text. There is no anonymous selling.

Please shrink the video first so neighbors on slow connections can watch it. Aim for 480p, a CRF of about 28, and mono AAC at 64k, with faststart:

ffmpeg -i input.mp4 -vf "scale=-2:480" -c:v libx264 -crf 28 -preset medium -pix_fmt yuv420p -c:a aac -ac 1 -b:a 64k -movflags +faststart "listings/Kids Bike - Breck - Wahiawa - 40 - 808-555-0123.mp4"
